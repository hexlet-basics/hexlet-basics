### ⚠ BREAKING CHANGES

* **api:** startLesson is public and returns the learner's position instead of 204. A guest progresses under the same rule, so the start command has to answer them too: it validates the gate and returns their position without storing anything, since only a check can move a cookie. Being public means it no longer carries the double-submit XSRF requirement, which is the same posture the check already has and which the SameSite=Lax session cookie covers — a cross-site POST carries no session to act with. Nothing consumes either operation yet: the player does not exist.
* **api:** name the fields after the concept, not the column
* **api:** move the admin routes onto the domain vocabulary
* **api:** rename the member family and the course-readiness enum
